# /biblia: a bíblia do projeto
## Como usar
Seguir a skill **`story-bible-builder`** (Joey) para a entrevista e o formato. Esta camada só acrescenta o contexto Eagle:
- Guardar em `negocio/clientes/<slug>/biblia.md`.
- O Yax tem pouco tempo: perguntas em bloco, aproveitar tudo o que já está no roteiro/brief/storyboard; marcar `[TBD]` em vez de perguntar o que não é urgente.
- Ferramentas por defeito: imagem = **Gemini (Nano Banana Pro)** do Yax · vídeo = **Kling** do Yax (ou Seedance via fal, se houver saldo).
- Regras de produção Eagle a meter sempre na secção "Production rules": as de `negocio/processos/videoclipe-ia.md`.
