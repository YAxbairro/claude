# Produção · Videoclipe "São Vicente"

## Pipeline (consistência)
1. **Fichas** de cada personagem e lugar → `personagens/`, `lugares/` ✅
2. **Imagem inicial de cada cena** = Seedream v4 *edit* com a ficha da personagem + o lugar como referência → `cenas/NN.jpg`
3. **O Yax aprova** cada imagem (ou pede ajustes)
4. **Vídeo** = Kling image-to-video, 5 s, 1080p, a partir da imagem aprovada → `cenas/NN.mp4` (não commitar MP4s)
5. **Montagem** pelo Yax: câmara lenta, cor única, grão de filme
