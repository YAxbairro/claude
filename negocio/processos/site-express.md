# Processo · Site Express (48–72h)

**Recebe do cliente:** nome, logótipo, 5–10 fotos, serviços/preços, morada, horário, WhatsApp, redes sociais.

1. **Claude:** constrói a página (Next.js/HTML) → deploy de prévia no Vercel.
2. **Yax:** revê no telemóvel → envia o link ao cliente.
3. **Ajustes:** 1 ronda.
4. **Domínio:** o cliente compra o domínio (ou nós, +20 €) → ligar ao Vercel.
5. **Entrega:** depois dos 50% finais. Oferecer manutenção a 30 €/mês.

**Truque de venda:** fazer a prévia ANTES de vender (demo grátis) para negócios com bom potencial.
