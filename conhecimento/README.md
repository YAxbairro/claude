# Base de conhecimento

Tudo o que aprendemos fica aqui, organizado, até termos uma base sólida que responda a tudo.

| Pasta / ficheiro | O que guarda |
|---|---|
| `perguntas/` | Uma ficha por pergunta respondida: pergunta, resposta curta, explicação, fontes com citação exata, o que falta saber. |
| `fontes/indice.md` | Registo de todas as fontes usadas (leis, sites oficiais, notícias), para que servem e se já estão no Djobe. |
| `ideias-e-decisoes.md` | As tuas sugestões, preferências e decisões. |
| `trabalho/registo.md` | O que foi feito, quando e onde está. |

## Regras
1. Cada pergunta: procurar em todas as fontes possíveis (leis no Boletim Oficial, sites oficiais, imprensa) antes de responder.
2. Só se guarda como resposta o que tem fonte verificada. O resto fica em "O que falta saber".
3. Uma lei nova encontrada vai também para o Djobe (`djobe/scripts/build_kb.py`), com um caso de teste em `djobe/tests/cases.json`.
4. Notícias datam rápido: indicar sempre a data em que foram consultadas.
